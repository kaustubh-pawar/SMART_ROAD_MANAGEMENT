Railway Cloud Deployment Ready

How to deploy to Railway and enable ESP32-CAMs & any other device to connect from anywhere

When deployed on Railway, this server receives an automatic global HTTPS domain (e.g., https://smart-road.up.railway.app). The ESP32-CAM firmware in Smart_Road_ESP32_CAM.ino is pre-configured with cloud URL support, allowing cameras on any Wi-Fi hotspot or mobile 4G/5G connection to upload road images and GPS data directly to Railway.

How to Deploy to Railway (3 Easy Steps)

Step 1: Push Project to GitHub git add . && git commit -m "Deploy Smart Road System" && git push
Step 2: Connect Repository on Railway

Open railway.app, click "New Project" → "Deploy from GitHub repo" → select this repository. Railway automatically reads Procfile and railway.json.

Step 3: Generate Public Domain

In Railway project settings, click "Generate Domain". You will get a URL like: https://smart-road-production.up.railway.app.

ESP32-CAM Firmware Configuration

In Smart_Road_ESP32_CAM.ino, set: 

// Set to true to connect to your Railway deployment
const bool USE_CLOUD_SERVER = true; 
const char* CLOUD_SERVER_URL = "https://your-project.up.railway.app/upload";

// Camera Identifier (CAM_001, CAM_002 for fleet)
const char* CAMERA_ID = "CAM_001";
Multiple Devices Support:

You can deploy 5, 10, or more ESP32-CAMs on different vehicles. Give each device a unique ID (CAM_001, CAM_002, etc.). The server organizes folders and reports per device automatically!

Hardware Pinout & Connections

NEO-6M GPS Module
  • GPS TX → ESP32 GPIO 13 (RX)
  • GPS RX → ESP32 GPIO 14 (TX)
  • GPS VCC → 3.3V / 5V
  • GPS GND → GND
Push Button (Capture Trigger)
  • Terminal 1 → ESP32 GPIO 2
  • Terminal 2 → GND
  • Internal pull-up enabled
  • Press reads LOW
Power & Flashing (FTDI)
  • FTDI TX → GPIO 3 (U0R)
  • FTDI RX → GPIO 1 (U0T)
  • Flash: GPIO 0 to GND
  • Run: GPIO 0 disconnected
